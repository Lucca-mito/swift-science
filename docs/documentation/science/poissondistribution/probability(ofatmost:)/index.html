probability(ofAtMost:)

The cumulative distribution function of the distribution.

func probability(ofAtMost value: Self.Value) -> Self.Statistic

Discussion

Complexity

O(value)

This is a default implementation of the CDF for discrete distributions with a lower bound. It simply sums probability(ofExactly:) from min to value, so it takes linear time. For this reason, probability distributions are encouraged to override this default implementation with a closed-form solution if one exists.
