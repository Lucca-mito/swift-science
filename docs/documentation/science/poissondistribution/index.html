PoissonDistribution

A Poisson distribution. In a process where independent events occur at a constant rate, the number of events that occur in a unit of time follows this distribution.

struct PoissonDistribution<Value, Statistic> where Value : BinaryInteger, Statistic : Real, Statistic : BinaryFloatingPoint, Value.Stride : SignedInteger
