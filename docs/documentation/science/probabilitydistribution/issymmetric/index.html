Instance Property

isSymmetric

Whether the distribution is symmetric.

var isSymmetric: Bool { get }

Discussion

For example, every NormalDistribution is symmetric about its mean value.

The distribution does not necessarily have to be symmetric about a valid Value for isSymmetric to be true. For example, BernoulliDistribution(probabilityOfOne: 0.5) is symmetric about the Value 0.5 even though 0.5 is not a valid Value for that distribution.
