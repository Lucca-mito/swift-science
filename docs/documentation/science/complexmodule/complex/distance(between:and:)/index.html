Type Method

distance(between:and:)

Returns the distance between two values, expressed as a Complex.Stride.

static func distance(
    between lhs: Complex<RealType>,
    and rhs: Complex<RealType>
) -> RealType

Return Value

The distance between lhs and rhs.

Discussion

This function must satisfy the four metric space laws:

  1. The distance from a point to itself is zero.

.distance(between: x, and: x) == .zero

  1. The distance between two distinct points is always positive.

// x != y
.distance(between: x, and: y) > .zero

  1. The distance from x to y is always the same as the distance from y to x.

.distance(between: x, and: y) == .distance(between: y, and: x)

  1. The triangle inequality holds:

.distance(between: x, and: z) <= .distance(between: x, and: y) + .distance(between: y, and: z)
