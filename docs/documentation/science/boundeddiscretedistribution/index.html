Protocol

BoundedDiscreteDistribution

A probability distribution over a finite set of values.

protocol BoundedDiscreteDistribution : BoundedDistribution, ClosedFormQuantile, DiscreteDistribution, DistributionWithMoments

Overview

Such a distribution always has a mean, a variance, and all other moments. Additionally, a BoundedDiscreteDistribution always has a ClosedFormQuantile.

Topics

Instance Properties

  • var support: Set<Self.Value>

    The finite set of values that have a positive probability of being sampled from this specific probability distribution.

Type Properties

    The finite set of values that may have a positive probability of being sampled in this family of probability distributions.
