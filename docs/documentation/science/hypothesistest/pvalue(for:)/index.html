Instance Method

pValue(for:)

Runs the hypothesis test on the given sample and reports the p-value

func pValue(for sample: Self.Sample) -> ProbabilityOfTypeIError

Parameters

sample

The sample data to run the test on.

Return Value

The smallest level at which the test rejects the null hypothesis. In other words, it’s the smallest ProbabilityOfTypeIError for this test given the sample.

Discussion

The closer the p-value is to 0, the more confident we can be that the data is incompatible with the null hypothesis.
