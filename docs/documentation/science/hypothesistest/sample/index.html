Associated Type

Sample

The type used for sample data.

associatedtype Sample

Discussion

If the hypothesis test concerns a single statistical population, Sample is usually [Double].

If the test concerns two populations, e.g. when testing whether two populations have the same mean, Sample is usually ([Double], [Double]). For an example of this, see sameMean.
