Instance Method

test(on:atLevel:)

Runs the hypothesis test on the given sample and either rejects or fails to reject the null hypothesis.

func test(
    on sample: Self.Sample,
    atLevel level: ProbabilityOfTypeIError = .lowProbability
) -> HypothesisTestOutcome

Parameters

sample

The sample data to run the test on.

level

If the null hypothesis is true, this is the probability that the test rejects it anyway. Denoted by 𝛼 in statistical literature and more accurately known as the test size.

Return Value

Whether the null hypothesis has been rejected.

Discussion

To get a p-value, use pValue(for:) instead.
