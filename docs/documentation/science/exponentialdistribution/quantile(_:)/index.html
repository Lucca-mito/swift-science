quantile(_:)

The distribution’s quantile function.

func quantile(_ quantileFraction: RealType) -> RealType

Parameters

quantileFraction

A probability.

Return Value

The smallest Value x such that probability(ofAtMost: x) ≥ quantileFraction.

Discussion

If the distribution’s cumulative density function is strictly increasing, then quantile(p) is the unique Value x such that probability(ofAtMost: x) == quantileFraction.
