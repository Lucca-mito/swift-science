Case

HypothesisTestOutcome.reject

Indicates sufficient evidence to reject the null hypothesis.

case reject

Discussion

This does not necessarily mean that we should accept the alternative hypothesis. For example, it could be that an improbable event has occurred during data sampling (meaning that the sampled data is an outlier, not the norm).
