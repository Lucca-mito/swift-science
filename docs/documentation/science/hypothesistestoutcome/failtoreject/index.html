HypothesisTestOutcome.failToReject

Indicates insufficient evidence to reject the null hypothesis.

case failToReject

Discussion

This does not necessarily mean that the null hypothesis is true. For example, it could be that the sample size is simply not large enough to conclusively reject the null hypothesis.
