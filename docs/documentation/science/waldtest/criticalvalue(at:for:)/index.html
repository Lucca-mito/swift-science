Instance Method

criticalValue(at:for:)

Calculates the critical value of the test.

func criticalValue(
    at level: ProbabilityOfTypeIError,
    for _: Sample
) -> Double

Deprecated

Use criticalValue(at:) instead. The critical value of the Wald test depends only on the level, and not on the sample size; this overload is kept only for conformance to the HypothesisTest protocol.

Parameters

level

The desired ProbabilityOfTypeIError for the test.

sample

The sample data to run the test on. In some tests, such as the WaldTest, the criticalValue depends only on the level and ignores this parameter.

Return Value

The critical value of the test. If the testStatistic(_:) exceeds this value, the null hypothesis is rejected.

Discussion

You rarely need to use this function directly. Use test(on:atLevel:) or pValue(for:) instead.
