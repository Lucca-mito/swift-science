Function

createHypothesisTest(testStatistic:criticalValue:pValue:)

Creates a single custom HypothesisTest without having to declare a new type.

func createHypothesisTest<Sample>(
    testStatistic: @escaping (Sample) -> Double,
    criticalValue: @escaping (ProbabilityOfTypeIError, Sample) -> Double,
    pValue: @escaping (Sample) -> ProbabilityOfTypeIError
) -> some HypothesisTest

Parameters

testStatistic

A function of the dataset that characterizes a type of hypothesis test. The test rejects the null hypothesis if testStatistic(data) exceeds the test’s critical value.

criticalValue

A function mapping the level (see test(on:atLevel:)) and the sample data to the test’s critical value. If the test statistic exceeds this value, the null hypothesis is rejected. In some tests, such as the WaldTest, the criticalValue depends only on the level and ignores the sample data.

pValue

A function mapping the dataset to the reported p-value. pValue(for:) wraps this closure.

Discussion

Use this function to create a custom single-purpose hypothesis test that doesn’t have test parameters. To create a custom type of hypothesis test, declare a structure conforming to HypothesisTest instead of using this function.
