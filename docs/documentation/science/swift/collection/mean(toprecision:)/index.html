Instance Method

mean(toPrecision:)

The arithmetic mean of the integer collection, computed to the specified FloatingPoint precision.

func mean<FloatingPointType>(toPrecision precision: FloatingPointType.Type = Double.self) -> FloatingPointType where FloatingPointType : FloatingPoint

Parameters

precision

The precision to which the mean should be computed. If omitted, defaults to Double precision.

Return Value

The mean as a FloatingPoint number.

Discussion

Precondition

The collection cannot be empty.
