sampleVariance(toPrecision:)

The sample variance of the integer collection.

func sampleVariance<FloatingPointType>(toPrecision precision: FloatingPointType.Type = Double.self) -> FloatingPointType where FloatingPointType : AlgebraicField, FloatingPointType : Euclidean, FloatingPointType : IntegerApproximable, FloatingPointType : FloatingPoint, FloatingPointType == FloatingPointType.Stride

Parameters

precision

The precision to which the variance should be computed. If omitted, defaults to Double precision.

Return Value

The sample variance as a FloatingPoint number.

Discussion

Precondition

There must be at least two elements in the collection.
