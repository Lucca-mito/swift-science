Instance Method

populationVariance(toPrecision:)

The population variance of the integer collection, computed to the specified FloatingPoint precision.

func populationVariance<FloatingPointType>(toPrecision precision: FloatingPointType.Type = Double.self) -> FloatingPointType where FloatingPointType : AlgebraicField, FloatingPointType : Euclidean, FloatingPointType : IntegerApproximable, FloatingPointType : FloatingPoint, FloatingPointType == FloatingPointType.Stride

Parameters

precision

The precision to which the variance should be computed. If omitted, defaults to Double precision.

Return Value

The population variance as a FloatingPoint number.

Discussion

Precondition

The collection cannot be empty.
