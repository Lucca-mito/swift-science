Type Method

squaredDistance(between:and:)

The square of the distance between two values.

static func squaredDistance(
    between lhs: Self,
    and rhs: Self
) -> Self.Stride

Return Value

The squared Euclidean distance between lhs and rhs.

Discussion

This function is used to define the population variance and the sample variance, but it’s also useful by itself. For example, the squared Euclidean distance is used in the method of least squares.
