Type Property

lowProbability

A probability of Type I Error that is commonly accepted as being low.

static let lowProbability: ProbabilityOfTypeIError

Discussion

Corresponds to a probability of 𝛼 = 0.05. A hypothesis test at this level is conservative about rejecting the null hypothesis. So, if it does reject the null hypothesis anyway, there is strong evidence against the null hypothesis.
