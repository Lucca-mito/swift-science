Protocol

Euclidean

A type whose distance between values is the length of the line segment between them.

protocol Euclidean : MetricSpace

Example

let sqDist: Double = Complex.squaredDistance(between: .i, and: 1)
print(sqDist.isApproximatelyEqual(to: 2)) // true

Conforming to the Euclidean protocol

Types conforming to Euclidean must implement a distance(between:and:) function that is equivalent to the Euclidean distance function.

Euclidean also defines a squaredDistance(between:and:) function with a default implementation that simply squares the result of distance(between:and:). Conforming types are encouraged to override this implementation if they have a better one, such as an implementation that is more numerically stable.
