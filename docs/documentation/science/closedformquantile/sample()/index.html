sample()

A default sampling function using inverse transform sampling.

func sample() -> Self.Value

Discussion

Tip

This default implementation makes it easy for distributions conforming to ClosedFormQuantile to also conform to Samplable. Distributions can choose to override this default implementation with a faster sampling function; for example, BernoulliDistribution does this.
