Protocol

Unimodal

A probability distribution that always has a single mode.

protocol Unimodal : FiniteModal

Overview

For example, NormalDistribution conforms to Unimodal because it always has a unique mode: its mean. In contrast, BernoulliDistribution does not conform to Unimodal because, although the mode of a Bernoulli distribution is almost always unique, the mode is not unique when probabilityOfOne = probabilityOfZero = 0.5.
